## Writing model

The editor is TipTap 3 with a Notion-like block experience. Top-level blocks receive stable `blockId`s through the UniqueID extension. Those ids anchor comments, live sync blocks, and source references for generated cards.

A page has two records: metadata (`Page`) and the document (`PageDocument`). The editor autosaves JSON into the local document, recomputes plain text and page-link edges, then queues a sync op.

## Blocks

Paragraphs, H1–H4, bulleted / numbered / task lists, toggles, quotes, callouts, dividers, code with syntax highlighting, tables, images, bookmarks, YouTube embeds, equations, page links, page embeds, synced blocks, and a structured database block.

The database block supports table, list, board, gallery, and calendar views over the same field/row JSON. It is intentionally lightweight: a structured block inside a page, not a separate product surface.

## Page links and backlinks

A `pageLink` node stores the target page id and display title. On save Lattice derives:

- a `REFERENCES` edge from source node to target node,
- backlink membership for the target,
- graph connectivity,
- link suggestions for related pages.

Removing a link soft-deletes its derived edge. Manual typed relations are separate and never removed by link cleanup.

## API requests

The `request` block documents an endpoint and can call it from the page.

- Pick a method, enter a URL, and optionally add headers as `Key: value` lines
  and a body (sent for everything except `GET` and `HEAD`).
- **Send** shows status, duration, size, response headers, and the body, with
  JSON pretty-printed.
- Requests run in your browser, so the target must allow cross-origin requests.
  A blocked request reports the browser's CORS error instead of pretending to
  succeed.
- Responses are transient: they are never saved into the note. Only the request
  definition is stored and synced.

Read-only surfaces, including public shares, show the request definition with a
note that it runs in the workspace. Markdown export writes an `http` fence.

## Templates

**Page actions → Save as template** copies a page's body and properties into a
workspace template. Later edits to the source page do not change it.

Templates are available from **⌘K → New page from template**, alongside the
built-in set: blank, meeting notes, ADR, research brief, project brief, weekly
review, learning note, decision log, and troubleshooting guide. Custom
templates are grouped under **Your templates** and can be deleted from the
picker.

Templates are workspace records, so they sync like any other content. A page
created from a template also inherits the template's properties.

## Diagrams

The `diagram` block renders Mermaid as SVG. It is a first-class block, not a
screenshot, so it stays editable, themes with the app, and prints cleanly.

- Insert from the `/` menu, or use **Page actions → Diagram from outline** to
  turn the page's heading tree into a flowchart.
- Edit the Mermaid source inline; `⌘↵` applies, `Escape` cancels.
- Flowcharts, sequence, class, state, ER, gantt, pie, journey, mindmap, and the
  other Mermaid diagram types all render.
- Mermaid is lazy-loaded, so notes without diagrams never pay for it.

Diagrams render in the editor, the read-only page reader, transclusions, and
public share pages. The mobile companion shows the diagram source instead,
because Mermaid needs a DOM.

Markdown export writes a ```` ```mermaid ```` fence, so diagrams survive a
round-trip through Markdown. A ```` ```mermaid ```` code block imported from
Markdown also renders as a diagram in read-only views.

## Page context

The right panel contains:

- **Info** — page properties, outline, tags, source cards, AI entry points.
- **Links** — backlinks and outgoing page links.
- **Discuss** — page and block-anchored comments with resolve state.

### Properties

The Info tab lists the page's properties and lets you add, edit, and remove
them. Properties are key/value text pairs stored on the page record, so they
sync and appear in the JSON export.

Creating a page from a template copies the template's properties as well as its
body.

## Modes

- **Document** — the default writing surface.
- **Focus** — chrome hidden, wider calm.
- **Markdown** — round-trip the document through a Markdown serializer/importer.
- **Outline** — heading and list structure in the context panel.

## Versions

Explicit versions can be saved. Conflicts also create snapshots. Restoring a version always creates a new snapshot first, so history is never destructive.
