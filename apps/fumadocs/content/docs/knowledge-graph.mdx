The graph is derived from the same records the editor and canvas use. It is not a separate index that can drift out of date.

## Nodes

Every page and canvas has a graph node. Additional topic, concept, project, person, and resource nodes can be created manually. Nodes carry title, kind, optional pinned position, color, and an `aiGenerated` flag.

## Edges

| Relation | Meaning |
| --- | --- |
| `RELATED_TO` | Loose conceptual connection |
| `DEPENDS_ON` | Requires the target |
| `PART_OF` | Belongs to a larger whole |
| `EXPLAINS` | Clarifies or teaches |
| `EXAMPLE_OF` | Concrete instance |
| `CONTRADICTS` | Conflicts with the target |
| `PREREQUISITE_OF` | Learn before the target |
| `REFERENCES` | Automatic internal page link |
| `CREATED_FROM` | Derived from another object |
| `CONNECTED_THROUGH` | Shared canvas or theme |

`REFERENCES` edges are maintained automatically when a document with `pageLink` nodes is saved. `CONNECTED_THROUGH` edges are derived from canvases: a linked note card or nested canvas on a whiteboard connects the canvas node to the page or canvas it references. Manual edges carry `origin: "MANUAL"`; AI suggestions can be accepted into manual edges or left as pending suggestions.

## Graph view

- Force-directed layout with a custom simulation.
- Zoom, pan, node dragging, and pinned positions.
- Filters by kind, notebook, tag, relation, recency, and orphans.
- Cluster coloring toggle, and a **local view** that focuses the selected node's
  neighborhood at 1–3 hops while the rest of the workspace stays one click away.
- Degree-aware labels and a node panel with incoming / outgoing relations.
- Create a topic; connect it to any existing node.
- Orphan detection for disconnected notes.
- Shared read-only graph links.

## AI suggestions

**Suggest** asks the server for missing connections based on shared vocabulary.
Suggestions render as dashed orange lines across the graph and as a list in the
node panel and the floating card. Accepting one writes a `RELATED_TO` edge with
`origin: "AI"` and `aiGenerated: true`, so the suggestions you took remain
distinguishable from hand-made relations.

## Learning path

Dependency-shaped graphs feed the learning view. `PREREQUISITE_OF` and `DEPENDS_ON` edges order concepts; card mastery adds a per-node score. Nodes with inbound dependencies and low mastery are surfaced as knowledge gaps.
