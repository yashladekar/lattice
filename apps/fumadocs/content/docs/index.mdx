Lattice is a knowledge workspace built around five verbs: **Create, Connect, Visualize, Understand, and Build**.

It is not a note app with a graph bolted on. Pages, whiteboards, topics, typed relations, captures, and flashcards all share one underlying model. Every view is a lens over the same records.

## Product principles

1. **One knowledge model.** A whiteboard card and a page refer to the same object. A database row can link to a page. A flashcard remembers its source block.
2. **Local-first by default.** Reads and writes go to IndexedDB before the network. Sync is a feature, not a prerequisite for opening your workspace.
3. **Connections are first-class.** Automatic page-link edges and manually typed relations live in the same graph.
4. **AI is optional and accountable.** Every answer cites notes. Generated content is labeled and requires an explicit action to keep.
5. **Calm software.** Dense capability without visual noise. Keyboard-first, but never keyboard-only.
