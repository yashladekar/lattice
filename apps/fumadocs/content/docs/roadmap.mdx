## Implemented in this pass

- Multi-tenant workspaces, organizations, invites, roles, and resource visibility.
- Local-first IndexedDB repository, outbox, snapshot, cursor pulls, conflict preservation.
- Block editor with slash menu, mentions, page links, embeds, synced blocks, database block, Mermaid diagrams, page properties, comments, versions, Markdown mode, and focus mode.
- Infinite whiteboard with shapes, notes, freehand, connectors, linked notes, nested canvases, templates, presentation, and export.
- Derived knowledge graph with typed edges, filters, orphan detection, manual relations, and AI suggestions.
- Universal capture inbox, quick capture, URL preview, and capture-to-page.
- Workspace JSON export/import, per-page Markdown, GitHub Markdown import with two-way Git sync, and Obsidian and Notion vault import.
- Learning decks, generated and manual cards, SM-2 review, quizzes, mastery, paths, and gaps.
- Optional AI with citations and local fallback.
- Dashboard widgets, command palette, tabs, keyboard-first navigation, search, timeline, trash.
- Share links for pages, canvases, notebooks, and graphs; public read-only surfaces.
- Comments, mentions, notifications, presence heartbeats, audit log, devices.
- Web, PWA shell, Tauri packaging config, Expo companion, self-host Docker.
- Fumadocs product/architecture documentation.

## Shipped: live co-editing

- Yjs co-editing for page documents and whiteboards over a WebSocket relay, with a room per resource.
- Live cursors and selection presence in the editor.
- Conflict-free concurrent typing; both peers converge without conflict snapshots.
- Whiteboard edits merge per field, so two people moving different shapes, or editing different fields of one shape, both survive.
- Presence and live cursors on the whiteboard, at canvas coordinates.
- The document is persisted per resource and flushed when the last peer leaves, so a session outlives its room and an edit made just before a tab closes is not lost.

## Next: collaboration depth

- Suggested edits and review workflows.
- Granular block-level comments and discussion resolution at scale.

## Shipped: query console

- Read-only SQL over workspace-scoped views, with a result grid and schema browser.
- Write and schema-escape attempts rejected by a tested validator, and by Postgres itself.

## Next: enterprise

- SSO and SCIM.
- End-to-end encryption with key custody and recovery.
- Retention policies, legal hold, export on demand.
- Organization-managed storage regions and BYOK.
- Retention policies and purge. A CSV audit export ships today. Note before building
  this: every `DELETE` op is a soft delete (`deletedAt`), for pages, canvases,
  notebooks and edges alike, so an "empty trash" button that removed rows locally
  would leave both sides disagreeing and resurrect content on the next pull. The
  shape that works is one server-side job purging soft-deleted rows past an age the
  workspace chooses, with clients reflecting the result; immediate manual purge needs
  its own op semantic and apply path.
- Legal hold.

## Shipped: duplicate review

- Near-duplicate pages found by exact title, drifted title, or repeated body, with the evidence recorded per group.
- A Duplicates tab that shows each group with excerpts and archives the ones you do not keep, recoverable from Trash.

## Next: knowledge intelligence

- Embedding-based semantic search with a vector index.
- Graph queries in natural language.
- Temporal graph playback across note versions.
- AI-generated diagrams previewed on the canvas before applying.

## Next: capture and ingestion

- Email ingestion.
- Audio transcription / speech-to-text.
- Browser extension distribution.
- PDF text extraction and attachment OCR.
- Unattended Git sync: the two-way sync runs today, but driven by a person with a token, not on a schedule.

## Shipped: plugin runtime

- Capability-checked worker isolation, with per-capability consent and revocation.
- Ambient network and database access removed before plugin code loads.

## Next: platform ecosystem

- A plugin directory and remote install; installing is local-only today.
- Custom blocks and custom canvas tools from plugins.
- Custom object types and property schemas.
- Automation triggers and webhooks.
- Import/export round-trip for Notion, Obsidian, and Markdown vaults.

## Explicit non-goals for this release

This build does not claim production-grade E2E encryption, SSO/SCIM, or app-store signing. The data model and service boundaries are designed so these can be added without replacing the knowledge model.
